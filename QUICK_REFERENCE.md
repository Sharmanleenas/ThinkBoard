# ThinkBoard - Quick Reference Guide\n\n## 🚀 QUICK START\n\n### Terminal 1: Backend\n`bash\ncd d:\\thinkbroad-mern\\backend\nnpm install\nnpm run dev\n`\n**Runs on:** `http://localhost:5000`\n\n### Terminal 2: Frontend\n`bash\ncd d:\\thinkbroad-mern\\frontend\nnpm install\nnpm run dev\n`\n**Runs on:** `http://localhost:5173`\n\n---\n\n## 🎯 PROJECT STRUCTURE\n\n### What Each Folder Does\n\n**Backend (`backend/`)** - Node.js + Express server\n- `server.js` - Main application entry point\n- `config/` - Database & Redis setup\n- `models/` - MongoDB schemas\n- `controllers/` - Business logic for each route\n- `routes/` - API endpoint definitions\n- `middleware/` - Rate limiting middleware\n\n**Frontend (`frontend/`)** - React + Vite app\n- `src/App.jsx` - Main app component with routing\n- `src/pages/` - Full page components (Home, Create, Detail)\n- `src/components/` - Reusable components (Navbar, NoteCard, etc)\n- `src/lib/` - Helper files (axios config, utilities)\n\n---\n\n## 📱 USER WORKFLOWS\n\n### View All Notes\n`\nHome Page (/) \n  ↓\nFetch all notes from /api/notes\n  ↓\nDisplay in responsive grid (1-4 columns)\n  ↓\nEach note is a clickable card\n`\n\n### Create New Note\n`\nClick \"New Note\" button\n  ↓\nNavigate to /create\n  ↓\nFill title & content\n  ↓\nClick \"Create Note\"\n  ↓\nPOST to /api/notes\n  ↓\nShow success & redirect to home\n`\n\n### Edit Existing Note\n`\nClick on note card\n  ↓\nNavigate to /note/:id\n  ↓\nEdit title/content in form\n  ↓\nClick \"Save Changes\"\n  ↓\nPUT to /api/notes/:id\n  ↓\nShow success & redirect to home\n`\n\n### Delete Note\n`\nClick delete button (trash icon)\n  ↓\nConfirm deletion popup\n  ↓\nDELETE /api/notes/:id\n  ↓\nNote removed from list immediately (optimistic update)\n  ↓\nShow success message\n`\n\n---\n\n## 🔧 KEY FILES & THEIR PURPOSE\n\n### Backend\n\n| File | Purpose | Key Functions |\n|------|---------|----------------|\n| `server.js` | Main server setup | Configure middleware, start server |\n| `config/db.js` | MongoDB connection | Connect to database |\n| `config/upstash.js` | Rate limiter config | Set up Redis rate limiting |\n| `middleware/rateLimiter.js` | Request limiting | Check rate limit before processing |\n| `models/Note.js` | Database schema | Define note structure |\n| `routes/notesRouter.js` | URL routing | Map HTTP methods to controllers |\n| `controllers/notesController.js` | Business logic | Handle CRUD operations |\n\n### Frontend\n\n| File | Purpose | Key State/Functions |\n|------|---------|---------------------|\n| `App.jsx` | App root & routing | Define all routes |\n| `pages/HomePage.jsx` | List all notes | `notes`, `setNotes`, `isRateLimited` |\n| `pages/CreatePage.jsx` | Create form | `title`, `content`, `handleSubmit` |\n| `pages/NoteDetailPage.jsx` | View & edit | `note`, `handleSave`, `handleDelete` |\n| `components/Navbar.jsx` | Top nav bar | Logo & create button |\n| `components/NoteCard.jsx` | Note display | `handleDelete`, `handleCardClick` |\n| `lib/axios.js` | API config | Base URL: `http://localhost:5000/api` |\n| `lib/utils.js` | Helpers | `formatDate()` |\n\n---\n\n## 🔌 API ENDPOINTS REFERENCE\n\n`javascript\n// Get all notes\nGET /api/notes\nResponse: [...notes]\n\n// Get single note\nGET /api/notes/:id\nResponse: {...note}\n\n// Create note\nPOST /api/notes\nBody: { title: string, content: string }\nResponse: { message, data: {...note} }\n\n// Update note\nPUT /api/notes/:id\nBody: { title: string, content: string }\nResponse: { message, data: {...note} }\n\n// Delete note\nDELETE /api/notes/:id\nResponse: { message }\n\n// Error response\n429 - Too many requests\n404 - Note not found\n400 - Validation error\n500 - Server error\n`\n\n---\n\n## 🐛 CRITICAL BUGS THAT WERE FIXED\n\n### 1.
