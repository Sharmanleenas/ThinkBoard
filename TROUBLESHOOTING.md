# 🚨 TROUBLESHOOTING GUIDE\n\n## Before You Debug: Check These First\n\n### 1. **Backend Not Starting?**\n\n**Error: \"Cannot find module 'xyz'\"**\n`bash\ncd backend\nnpm install\nnpm run dev\n`\n\n**Error: \"Port 5000 already in use\"**\n`bash\n# Option 1: Kill process on port 5000\nlsof -ti:5000 | xargs kill -9\n\n# Option 2: Change port in .env\nPORT=5001\n`\n\n**Error: \"MongoDB connection failed\"**\n- Check MONGO_URI in .env\n- Verify it's a valid connection string\n- Ensure MongoDB Atlas IP is whitelisted\n- Try connecting: `mongodb+srv://user:password@cluster.mongodb.net/dbname`\n\n**Error: \"Rate limiter not working\"**\n- Verify UPSTASH_REDIS_URL in .env\n- Check UPSTASH_REDIS_TOKEN\n- Ensure no typos in environment variables\n\n---\n\n### 2. **Frontend Not Starting?**\n\n**Error: \"Cannot find module 'xyz'\"**\n`bash\ncd frontend\nnpm install\nnpm run dev\n`\n\n**Error: \"API requests returning 404\"**\n- Backend running? Check `http://localhost:5000`\n- Port mismatch? Check `frontend/src/lib/axios.js` has `5000` not `5001`\n- Routes mounted? Check `backend/server.js` line with `app.use(\"/api/notes\", notesRouter)`\n\n**Error: \"Cannot GET /note/:id\"**\n- React Router issue\n- Check `frontend/src/App.jsx` routes are defined\n- Ensure NoteDetailPage is imported\n\n**Error: \"Style issues or components look wrong\"**\n`bash\n# Rebuild Tailwind CSS\nnpm run build\n# Or refresh browser (Ctrl+Shift+R)\n`\n\n---\n\n### 3. **API Call Issues**\n\n**Error: \"Failed to create note\"**\n\nCheck these in order:\n1. Backend running on 5000? (not 5001)\n2. Did you fill in title AND content?\n3. Are you hitting rate limit?\n4. Check browser console error details\n\n`javascript\n// Debugging: Add this to see error details\ncatch (error) {\n  console.error(\"Full error:\", error);\n  console.error(\"Status:\", error.response?.status);\n  console.error(\"Data:\", error.response?.data);\n}\n`\n\n**Error: 429 (Too Many Requests)**\n\nThis is rate limiting working correctly:\n- Limited to 5 requests per 20 seconds\n- Wait 20 seconds before trying again\n- Or disable rate limiter for testing:\n - Comment out `app.use(rateLimiter)` in server.js\n - Replace with: `app.use((req, res, next) => next())`\n\n**Error: 404 (Not Found)**\n\nNote doesn't exist:\n1. Check the ID is valid (from database)\n2. Verify note wasn't deleted\n3. Check database has data: `db.notes.find()`\n\n**Error: 400 (Bad Request)**\n\nValidation failed:\n1. Title is required (can't be empty)\n2. Content is required (can't be empty)\n3. No extraneous fields in request body\n\n---\n\n### 4. **Frontend Issues**\n\n**\"Loading spinner doesn't show\"**\n- Check: Is `Loader` imported from lucide-react? (Not LoaderIcon)\n- Check: Is it rendering with proper props?\n- Check: Browser console for errors\n\n`javascript\n// CORRECT:\nimport { Loader } from \"lucide-react\";\n<Loader className=\"animate-spin text-primary size-12\" />\n\n// WRONG:\nimport { LoaderIcon } from \"react-hot-toast\";  // Doesn't exist!\n`\n\n**\"Buttons don't navigate\"**\n- Check: Is `Link` imported from `react-router-dom`? (Not react-router)\n- Check: Is `to` prop set correctly?\n\n`javascript\n// CORRECT:\nimport { Link } from \"react-router-dom\";\n<Link to=\"/create\">Create Notes</Link>\n\n// WRONG:\nimport { Link } from \"react-router\";  // Wrong package!\n`\n\n**\"Toast notifications not showing\"**\n- Check: Is `<Toaster />` in App.jsx?\n- Check: Is it inside the main div?\n- Check: Position is set? `<Toaster position=\"top-right\" />`\n\n`javascript\n// CORRECT:\n<div className=\"min-h-screen\">\n  <Toaster position=\"top-right\" />\n  <div className=\"relative z-10\">\n    <Routes>...</Routes>\n  </div>\n</div>\n\n// WRONG:\n// Toaster inside Routes\n// Toaster position not set\n`\n\n**\"Form doesn't submit\"**\n1. Check inputs have `value` and `onChange`\n2. Check form has `onSubmit` handler\n3. Check button has `type=\"submit\"`\n4. Check no console errors\n\n`javascript\n// CORRECT:\n<form onSubmit={handleSubmit}>\n  <input value={title} onChange={(e) => setTitle(e.target.value)} />\n  <button type=\"submit\">Submit</button>\n</form>\n\n// WRONG:\n// Button missing type=\"submit\"\n// onChange handler missing\n// Form missing onSubmit\n`\n\n---\n\n### 5. **Database Issues**\n\n**\"Notes not appearing in list\"**\n1. Check backend created notes: Connect to MongoDB and run: `db.notes.find()`\n2. Check frontend is calling correct API: Should see network request in DevTools\n3. Check response status: Should be 200, not 404\n4. Check data structure: Each note needs `_id`, `title`, `content`\n\n**\"Note updates not persisting\"**\n1. Check backend received PUT request: Look for 200 status\n2. Check data in request: title & content should be strings\n3. Verify note ID is valid\n4. Check MongoDB document was updated\n\n**\"Can't delete notes\"**\n1. Check DELETE request is sent: DevTools → Network → DELETE\n2. Check response status: Should be 200\n3. Check note ID in URL is correct\n4. Verify optimistic update isn't hiding deletion failure\n\n---\n\n## Common Error Messages & Fixes\n\n| Error | Cause | Fix |\n|-------|-------|-----|\n| \"Cannot find module 'axios'\" | Missing dependency | Run `npm install` |\n| \"localhost:5001 refused\" | Wrong port | Change to 5000 in axios.js |\n| \"LoaderIcon is not a function\" | Wrong import | Use `Loader` from lucide-react |\n| \"Link is not a valid React element\" | Wrong import | Import from react-router-dom |\n| \"Cannot read property '\_id' of undefined\" | Note not loaded | Check useEffect dependencies |\n| \"Too many requests\" | Rate limit hit | Wait 20 seconds |\n| \"CORS error\" | Backend/frontend mismatch | Check CORS config in server.js |\n| \"Cannot POST /notes\" | Route not defined | Check notesRouter mounted |\n| \"MongoError: connect ECONNREFUSED\" | MongoDB not running | Start MongoDB service |\n| \"SyntaxError: Unexpected token\" | JSON parsing error | Check API response format |\n\n---\n\n## Debugging Techniques\n\n### 1. **Check Backend is Running**\n`bash\n# Try this URL in browser:\nhttp://localhost:5000\n# Should see: \"🚀 Backend API is running...\"\n`\n\n### 2. **Check Frontend is Running**\n`bash\n# Try this URL in browser:\nhttp://localhost:5173\n# Should see: ThinkBoard app loads\n`\n\n### 3. **Check Network Requests**\n1.
